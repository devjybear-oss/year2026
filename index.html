Second-Half Growth Plan

จากประสบการณ์ครึ่งปีแรก สู่สิ่งที่จะพัฒนาต่อ

Deeper Business Ownership

  • ศึกษา Payment และ PayOut แบบ End-to-End
  • เชื่อมโยง Transaction, Fee, Settlement และ Report
  • จัดทำ Payment Business Presentation

Value: วิเคราะห์ Requirement และ Incident ได้เร็วขึ้น พร้อมลดการพึ่งพาผู้อื่นในระยะยาว

Stronger Engineering Quality

  • เพิ่ม Automated Test ใน Critical Flow
  • ตรวจสอบ Code Coverage และคุณภาพ Test Case
  • ศึกษาการนำ Test เข้าสู่ CI Pipeline
  • เข้าร่วม Code Review อย่างสม่ำเสมอ

Value: ลด Regression และช่วยตรวจพบความเสี่ยงก่อนขึ้น Production

Knowledge Sharing

  • จัดทำ SPOF Documentation
  • สร้าง System Flow และ Troubleshooting Guide
  • สรุป Common Error และแนวทางตรวจสอบ
  • แชร์ความรู้จากระบบที่รับผิดชอบให้ทีม

Value: ช่วยให้ทีมรับช่วงงานและแก้ไขปัญหาได้โดยไม่ขึ้นอยู่กับบุคคลเดียว

AI-Assisted Development

  • สร้าง Prompt Template สำหรับ Requirement และ Test Plan
  • ใช้ AI ช่วยค้นหา Edge Cases และ Regression Risk
  • ใช้ AI ช่วยจัดทำ Documentation และ Technical Summary
  • วัดเวลาที่ลดลงและคุณภาพงานที่เพิ่มขึ้น

Value: ลดเวลางานซ้ำ เพิ่มความครอบคลุม และทำให้ทีมใช้ AI ได้อย่างมีประสิทธิภาพมากขึ้น
