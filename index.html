01 · PayOut Fee Management

ระบบบริหารค่าธรรมเนียม PayOut

04 · Transaction Status

Pending

รองรับกรณีที่ระบบยังสรุปผลธุรกรรมไม่ได้ทันที จากกระบวนการ Check Payer Name และการตรวจสอบบัญชีม้าตามฐานข้อมูล AMLO

ปัญหาเดิม

  • ระบบกำหนดสถานะเป็น Success, Voided หรือ Rejected ทันทีเมื่อได้ผลการตรวจสอบ
  • บางกรณีทำต่อไม่ได้ เช่น Void กับธนาคารไม่สำเร็จ
  • ไม่ได้รับผลการตรวจสอบจากระบบ AMLO
  • ทำให้ไม่สามารถสรุปผลธุรกรรมได้อย่างถูกต้อง

แนวทางแก้ไข

  • เพิ่มสถานะใหม่ Pending เป็นสถานะชั่วคราว
  • ใช้กับรายการที่ต้องให้เจ้าหน้าที่ตรวจสอบเพิ่มเติม
  • รอสรุปผลรายการอีกครั้งเมื่อข้อมูลครบถ้วน
  • รองรับบน Web Frontend และฐานข้อมูลที่เกี่ยวข้อง
ไม่สรุปผลผิดพลาด

หลีกเลี่ยง Success / Voided / Rejected ก่อนข้อมูลครบ
