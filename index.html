Admin Transfer

Result / Outcome

พัฒนาและจัดทำขอบเขตฟีเจอร์ Admin Transfer สำหรับ Back-office ให้ทีมการเงินสั่งโอนผ่าน PayOut ได้เป็นระบบ ครอบคลุมการตั้งค่า Enable และจำนวนผู้อนุมัติระดับ Merchant, Flow อัปโหลด Excel → Validate → Check/Decline → Approve/Reject → ส่งต่อ PayOut รวมถึง Dashboard, Detail, Approval History และ Export

Challenge

Requirement เปลี่ยนบ่อย ต้องคุม Scope, Multi-approver และความเสี่ยงโอนซ้ำ พร้อมประสานหลายทีมให้สรุป Flow ได้ตรงกัน นอกจากนี้ระบบ PayOut ถูกปิดใช้งานระหว่างทาง ทำให้ทดสอบ End-to-End ต่อไม่ได้ตามแผน ส่งผลให้ส่งมอบล่าช้ากว่ากำหนด

Skills Growth

ออกแบบและพัฒนา UI ให้รองรับการใช้งานจริงของทีมการเงิน เรียนรู้การ Integration ระหว่าง Web Back-office กับ PayOut API และการจัดการ JSON Response ทั้งกรณีสำเร็จและผิดพลาด พร้อมเข้าใจ Domain ของระบบ PayOut มากขึ้น เช่น PayOut Merchant, PayOut Receiver, Balance
