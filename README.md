## วิธีเปิด

เปิดไฟล์ `index.html` ในเบราว์เซอร์ หรือรัน local server:

```bash
npx serve .
```

## การควบคุม

- `→` / `Space` / คลิก — หน้าถัดไป
- `←` — หน้าก่อน
- `F` — Fullscreen
- `Esc` — ออกจาก Fullscreen
- เลขสไลด์มุมล่างขวา
